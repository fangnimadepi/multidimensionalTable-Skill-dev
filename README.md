# 多维表格项目报告 Skill

本仓库用于开发可导入 WorkBuddy 的项目报告 Skill。项目经理人可使用本地文件或从飞书多维表格取材，生成报告，审阅后归档到对应项目记录。

首版规划三种报告：项目阶段履约审查、项目阶段成果与后续推进分析，以及仅有任务书时的预期成果分析。

当前为仓库初始化，Skill 尚未实现。个人配置、真实项目材料、生成报告和运行记录放在本地 `local/` 目录。报告模板和业务规则的参考版本见此前的「鲸研」项目。 [鲸研开发路线](https://github.com/fangnimadepi/projectManager-contractReview/blob/main/docs/next-iteration-plan.md)
