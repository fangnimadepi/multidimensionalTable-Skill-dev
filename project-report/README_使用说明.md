# 鲸研项目报告

将完整 Skill 文件夹或 ZIP 导入 WorkBuddy，连接你有权限使用的飞书账号。在 WorkBuddy 选择自己想用的模型，内置模型和自定义模型均可；鲸研默认使用当前模型，不需要再填 API Key。

选中「鲸研项目报告」，用一句话说明任务，例如：

> 为我飞书「项目进展看板」里的前三个项目生成履约审查和成果分析，并归档到原项目行。

也可以粘贴多维表格链接并指定项目名称。默认生成两份可编辑 Word，写回原项目的报告归档附件列。只想看草稿时，说「先生成给我预览，暂不写回」；只需要一类报告时直接说明；更新已有报告时说「重新生成并更新归档」。

鲸研会自行读取材料、提炼事实、撰写、自查、导出和归档。中间的阶段结果由 WorkBuddy 自动处理，不需要你填写技术文件。表格重名、材料有多个版本或缺归档列时，它会请你选择或确认。完成后会说明哪些报告已经归档，哪些项目还缺材料或遇到问题。

仅有任务书时，生成预期成果分析（任务书版），不会把计划写成已经完成的成果。履约审查等待补齐阶段总结。材料读取失败会单独说明，不冒充没有材料。

首次使用可说「使用鲸研，帮我完成初始化」。环境准备可能需要联网或确认运行权限，已有环境直接复用；扫描 PDF 才按需准备 OCR。处理时间随文件大小、扫描页数和模型变化，不承诺固定完成时长。遇到权限提示，请核对本次目录和操作，无需长期打开完全访问权限。

报告包含项目概况、计划与进展对照、出入点、综合意见与 PI 确认话术；成果稿含事实提炼、简版、科普长版、后续推进判断及可编辑文字卡片。附页集中列出关键材料位置，完整原文与过程记录留在本机工作目录。语义检查是当前模型自查，不是独立模型复核。

批量任务可指定项目名单或整表。若会话中断，下次说「继续上次鲸研批次」，它会核对保存记录后继续，报告生成与写回结果分别反馈。只有回读确认才算留档成功。

需要另外指定独立报告 API 时仍可保留并使用 config/model.local.json，但必须明确告诉 WorkBuddy 使用独立 API 模式，详见 [可选 API 配置](references/model-setup.md)。默认流程不会因为这个文件存在而自动切换。

当前支持任务书 DOCX、阶段总结 DOCX 或 PDF；旧版 DOC 可先用 Word/WPS 另存为 DOCX。输出 Word 可下载编辑，人工修改稿与程序原始输出区分留存。
