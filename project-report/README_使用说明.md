# 鲸研项目报告

将完整文件夹或 ZIP 导入 WorkBuddy 的技能列表，并连接有权限使用的飞书账号。首次使用可以对 WorkBuddy 说：

> 使用鲸研，帮我完成首次初始化和报告模型配置。模型用 DeepSeek Flash，打开本机密钥文件让我粘贴 API Key。

如果习惯手动配置，在已导入的技能目录里将 `config/model.example.json` 另存为 `config/model.local.json`，用记事本填写接口地址、模型名和密钥。保存后可以对 WorkBuddy 说「使用鲸研，检查我的报告模型连接」。详细步骤见 [个人报告模型配置](references/model-setup.md)。

首次准备环境需要网络；已有可用环境后会直接复用。设置完成，选中「鲸研项目报告」，用一句话说明需求即可，例如：

> 为我飞书「项目进展看板」里的全部项目生成履约审查和成果分析，并归档。

鲸研会识别材料列和项目范围；表格重名或找不到时，请补充链接。多份材料无法区分时会请你选择，缺少输出列时会询问是否创建。只处理部分项目可提供项目名单；已有报告需要更新时，说明「重新生成并更新归档」。

每个项目各自生成可编辑 Word。成果报告包含简版、科普长版和横版卡片。报告末尾列关键依据，完整引文及核对记录保存在本机工作目录。

需要批量时可指定项目名单或整表，鲸研先清点材料，再分组持续执行。若会话中断，下次说“继续上次鲸研批次”，先核对已保存记录再续跑。生成和附件写回结果会分别反馈。

报告以文字列明关键依据的材料位置，不依赖在线预览跳转。下载后可用 Word/WPS 编辑。人工编辑后的文件与程序原始输出区分留存。

当前输入支持任务书 DOCX、阶段总结 DOCX 或 PDF。旧版 DOC 可先用 Word/WPS 另存为 DOCX。网络或电脑管理策略阻止环境准备时，WorkBuddy 会指出具体步骤，方便联系技术支持。
