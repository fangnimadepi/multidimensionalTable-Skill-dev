# 成果表达通用方法

输入仅为当前项目任务书和总结报告，总结报告事实按已人工确认材料处理。首先整理问题、已有基础、已形成成果、结果与比较条件、阶段归属和后续方向。

沿“具体结果、形成的能力、对实际任务的改变、科学或应用价值”展开，优先讲清一个核心价值及一至两项代表结果。解释概念、机制和使用流程，面向行政岗位项目经理人写自然连贯的文字。

任务书中的目标与当前成果区分，前期基础与本期新增区分；研究、仿真、实验、试用与部署分别表述。软课题重点解释方法工具、政策建议、管理与决策支持，报送、批示、采纳和运行分别叙述。

实际数字、单位、时间、比较范围、成果归属及状态保留原文限制。允许有事实前提的合理分析和明确的示意场景，不能新增已实现收益、客户、部署或排名。跟进判断自然放在详述结尾，给出有依据的具体方向。

正文减少重复引用，来源集中展示；内部保留原文位置、事实绑定和独立核验记录。不引入其他项目、额外研究报告或外部检索事实。
