# 材料与依据

## 识别项目和阶段

- 核对材料内的项目名称、编号（如有）、承担单位或执行期。编号缺失可由其他标识和用户指定记录共同确认。正文标识冲突、总结报告对应阶段不明且会改变结论时，说明需要确认的信息。相同文件名不能证明同项目，文件名不同也可配对。
- 优先读任务书的项目概况、考核指标与测评方式、里程碑、年度目标和交付要求。优先读总结报告的目标完成表、实施及代表成果、总结与下一步计划。为解释项目问题和成果用途，按需查看其他相关章节。首页表格只填可确认的项目名称、编号、承担单位、负责人、项目经理人、执行期等，缺失字段省略。
- 区分计划节点、材料所述事实时间和审查基准日。日期以用户指定或原材料明确标记为准。文件生成日期、文件名和文档落款可辅助识别材料，只有明确对应进展口径时才用作事实截止日。无可靠日期时仍可审查同阶段可比要求。跨阶段指标只有原文或用户明确绑定本期时才用于判定本期完成情况。

## 提取与定位

- 工具选择、实际落盘位置、解析失败处理和读取范围按 [材料存放与解析](material-handling.md) 执行。只有所需范围实际读取后，才将对应内容用于审查结论。
- DOCX 按标题、段落和表格读，保留表头及所在行。PDF 用 PDF 文件页序定位。文字层缺失或异常时，用可用的本地 OCR 或页面视觉能力识别相关页。能查看版面、封面或页数只说明文件能打开。重要数字、单位、符号和表格行列需回看页面，识别不清则标记具体页和字段。优先确认决定判断的章节及表格，说明未读取的范围。
- 同一项目的事实底稿分开记录计划要求、报告陈述、后续安排、可定位原文和待确认事项。总结报告自填的「完成」需与正文和指标表对照。附录可引用材料中的证明材料名称，清楚标明它由报告列出。实际未读取的附件、图表内容不得写成已复核。
- 为可改变结论的关键事实和数字记录文件角色、文件名、章节与段落或表格行、PDF 页码及短原文摘录。同名任务书和总结报告通过角色区分。摘录带足表头和上下文，跳过中间文字时分开标注。找不到原文时不要编造页码、链接或引文。优先使用材料原有数字，用户要求衍生数字时明确标注计算口径，避免把完成数量当作通过数量。
- 默认在附页集中呈现对应内容及原材料位置，正文需要时用普通文字指向附页，不放「查看本项依据」等跳转按钮。重复出处合并。完整引文和核对记录保存在本机底稿，每个实质差异能追溯到两侧材料，报告内部矛盾能追溯到双方表述。
